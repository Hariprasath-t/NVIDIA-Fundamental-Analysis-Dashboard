 NVIDIA Fundamental Financial Analysis Dashboard
 
 An Excel-based financial analysis project that evaluates NVIDIA’s fundamental performance using financial data collected from NVIDIA Investor Relations. 
 
 Data Source
Financial data collected from NVIDIA Investor Relations.

 Tools Used
- Microsoft Excel
- Data Cleaning and Transformation
- Pivot Tables
- Pivot Charts
- KPI Reporting
- Financial Analysis

 Key Metrics Analyzed
- Revenue
- Net Profit
- Total Assets
- Total Liabilities
- Cash on Hand
- Total Debt
- Stock Price

 Project Workflow
1. Collected financial data from NVIDIA Investor Relations.
2. Cleaned and organized the raw data in Excel.
3. Created pivot tables to analyze financial performance across reporting periods.
4. Developed KPI metrics for revenue, profit, assets, liabilities, cash, debt, and stock price.
5. Converted the analysis into clear charts and dashboard visuals.
6. Identified trends in NVIDIA’s financial health and business performance.

 Dashboard Features
- KPI cards for key financial metrics
- Revenue and profit trend analysis
- Asset, liability, cash, and debt comparison
- Stock-price performance visualization
- Pivot-table-based analysis
